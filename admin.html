Portfolio Editor

LOCAL MODE: choose your portfolio folder, upload pictures/videos directly into its assets folder, then download content.js and replace the existing file. Nothing is published to GitHub.

GitHub connection (one time)

1. On github.com click your photo, then Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
2. Repository access: “Only select repositories”, then choose your portfolio repository.
3. Repository permissions → Contents: Read and write.
4. Set the expiry (for example 90 days), click Generate, copy the token and paste it below.
The token works like a password for this one repository. It is saved only in this browser on this computer. Never share it.
